# RazorKit

Welcome to the **RazorKit** documentation. RazorKit is a collection of reusable UI components for ASP.NET Core MVC, delivered as Razor partial views with their CSS and JavaScript.

---

## Key Features

- ⚡ **Razor partial views**: Components are rendered with `@await Html.PartialAsync("UI/_Name", model)` or the built-in `<partial name="UI/_Name" />` tag helper.
- 🧾 **Documented parameters**: Each component page lists its parameters and includes usage examples and source code.
- 📊 **Client-side grid**: `DataTable` is a JavaScript data grid initialized with `RazorKit.DataTable.render(...)`.

---

## Component Architecture & Structure

Each component typically consists of:

1. **Razor Markup (`_*.cshtml`)**: A partial view rendered by the ASP.NET Core view engine.
2. **Model parameters**: Configuration passed as the partial view model, usually an anonymous object. See each component's parameter table.
3. **Styles & Scripts**: Component CSS and JavaScript. Some components rely on third-party libraries such as Bootstrap, jQuery, CKEditor 5, or jTable; check each component page for its requirements.

## Component Library Overview

### 📝 Form Controls
Inputs for data entry, validation, and user selection.

| Component | Description |
|---|---|
| **DualDate** | Dual Hijri & Gregorian date selector with custom date constraints. |
| **DateInput** | Read-only date input (Hijri or Gregorian) initialized by an app-provided calendar function. |
| **DateRange** | Single date or date-range picker (Hijri or Gregorian) with required validation. |
| **InputField** | Labelled Bootstrap input with configurable type and an optional initial value. |
| **AutoComplete** | AutoComplete & Search Select component with local/remote sources. |
| **SelectInput** | Native Bootstrap select with a label and an empty default option. |
| **SmartSelect** | Custom single or multi-select with optional search, clear button, and a JavaScript API. |
| **ChipSelect** | Multi-select dropdown with dismissible chips and search. |
| **FileUpload** | Drag-and-drop file picker with client-side size, type, and count checks. |
| **AttachBox** | Compact file attachment container widget. |
| **TextArea** | Labelled fixed-height Bootstrap textarea with an optional initial value. |
| **CkEditor** | Rich text WYSIWYG editor wrapper for Razor views. |

### 📊 Data Display
Components designed for rendering structured server data cleanly.

| Component | Description |
|---|---|

| **Badge** | Status tag and category badge component. |
| **AttachmentCard** | Attachment card with file name, description, and a preview button. |

### 💬 Overlays & Feedback
Popovers, alerts, and modal dialogs for contextual user interaction.

| **Notification** | Static notice box with an icon, title, and message. |

## Quick Example

Render a component inside any Razor View (`.cshtml`):

```cshtml
<partial name="UI/_DualDate" model='new {
    id          = "editor1",
    label       = "وصف الحالة",
    required    = true,
    placeholder = "",
    minDate     = "today",
    maxDate     = "+2m"
}' />
```

Explore components from the categories in the left sidebar or browse the [Components Gallery](/components).
