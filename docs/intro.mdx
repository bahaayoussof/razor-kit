# RazorKit

Welcome to the **RazorKit** documentation. RazorKit is a collection of reusable UI components for ASP.NET Core MVC, delivered as Razor partial views with their CSS and JavaScript.

---

## Key Features

- ⚡ **Razor partial views**: Components are rendered with `@await Html.PartialAsync("UI/_Name", model)` or the built-in `<partial name="UI/_Name" />` tag helper.
- 🧾 **Documented parameters**: Each component page lists its parameters and includes usage examples and source code.
- 📊 **Client-side grid**: `MomahTable` is a JavaScript data grid initialized with `MomahTable.render(...)`.

---

## Component Architecture & Structure

Each component typically consists of:

1. **Razor Markup (`_*.cshtml`)**: A partial view rendered by the ASP.NET Core view engine.
2. **Model parameters**: Configuration passed as the partial view model, usually an anonymous object. See each component's parameter table.
3. **Styles & Scripts**: Component CSS and JavaScript. Some components rely on third-party libraries such as Bootstrap, jQuery, CKEditor 5, or jTable; check each component page for its requirements.

## Quick Example

Render a component inside any Razor View (`.cshtml`):

```cshtml
<partial name="UI/_DualDate" model='new {
    id          = "editor1",
    label       = "وصف الحالة",
    required    = true,
    placeholder = "",
    minDate     = "today",
    maxDate     = "+2m"
}' />
```

Explore components from the categories in the left sidebar or browse the [Components Gallery](/components).
