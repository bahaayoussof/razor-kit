The `_Breadcrumb.cshtml` partial view renders a navigation breadcrumb trail using Bootstrap's breadcrumb component.

## Location

`Views/Shared/UI/_Breadcrumb.cshtml`

## Model Structure
The model type is `List<(string Name, string Url)>` (a list of tuples; the element names are optional). Each item contains:
- `Name`: The display text for the breadcrumb item
- `Url`: The link for the breadcrumb item

The list must not be `null`.

## Basic Usage

### In a Controller
```csharp
public IActionResult MyPage()
{
    var breadcrumb = new List<(string, string)>
    {
        ("Home", "/"),
        ("Section", "/section"),
        ("Subsection", "/section/subsection"),
        ("Current Page", "")  // Empty URL for the current page
    };

    return View(breadcrumb);
}
```

### In a View (Razor Page)
```cshtml
@model List<(string Name, string Url)>
@{
    ViewData["Title"] = "My Page";
}

<partial name="UI/_Breadcrumb" model="Model" />
```

### Example Implementation
```cshtml
@{
    var breadcrumb = new List<(string, string)>
    {
        ("الرئيسية", "/"),
        ("إدارة القضايا", "/cases"),
        ("تفاصيل القضية", "/cases/123")
    };
}
<partial name="UI/_Breadcrumb" model="breadcrumb" />
```

## Features
- **Right-to-left**: The list always has `dir="rtl"`, so items run from right to left regardless of the page direction.
- **Last item**: The link of the last item gets an `active` class and is shown in `#9DA4AE`. It remains a normal, clickable link (an empty `Url` links to the current page).
- **Responsive**: Hidden below Bootstrap's `sm` breakpoint (`d-none d-sm-flex`), visible from 576px up.
- **Styling**: Links use `#54565B`; the separator is `>` (set with `--bs-breadcrumb-divider`).

## Global Styles

The partial outputs a `<style>` block with **unscoped** rules for `a`, `a:hover`, and `a.active`. They apply to every link on the page, not only the breadcrumb: all links become `#54565B` without underline, and any link with the `active` class becomes `#9DA4AE`. The block is written every time the partial is rendered.

## Accessibility
- The `<nav>` has `aria-label="breadcrumb"`.
- `aria-current="page"` is set on **every** item, not only the last one, so assistive technology reports each item as the current page.

## Security Notes
- `Name` and `Url` use normal Razor encoding. URLs are not validated, so do not build them from untrusted input (for example, a `javascript:` URL would be rendered as a link).

## Dependencies
- Bootstrap 5 CSS (`breadcrumb`, `breadcrumb-item`, `d-none`, `d-sm-flex`)

```cshtml
@model List<(string Name, string Url)>

	<style>
		a {
			color: #54565B;
			text-decoration: none;
		}

		a:hover {
			color: #54565B;
		}

		a.active {
			color: #9DA4AE;
		}
	</style>

	<nav class="d-none d-sm-flex" style="--bs-breadcrumb-divider: '>';" aria-label="breadcrumb">
		<ol dir="rtl" class="breadcrumb" style="white-space:nowrap;">
			@for (int i = 0; i < Model.Count; i++) { var item=Model[i]; var isActive=i==Model.Count - 1; <li
				class="breadcrumb-item" aria-current="page">
				<a href="@item.Url" class="@(isActive ? " active" : "" )">@item.Name</a>
				</li>
				}
		</ol>
	</nav>
```
