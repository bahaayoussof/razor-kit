The `_AttachBox` partial view renders a single attachment row: the file name, a preview button, and a download link. Both actions use a URL built from an action path and the file's ID.

## Properties

You can use the partial in your views as follows:

```html
<partial name="UI/_AttachBox" model='new { FileId = "12345", FileName = "My Document.pdf" }' />
```

### Model Property Table

The model is an anonymous object; property names are case-insensitive.

| Property | Type   | Required | Default Value | Description |
| :--- | :--- | :--- | :--- | :--- |
| **FileId** | `string` | **Yes** | `""` | The ID of the attachment, e.g. `"27131"`. The download and preview URLs are `{ActionUrl}/{FileId}`. |
| **FileName** | `string` | No | Derived from `FileId` | The display name of the file (e.g., `"Resume.pdf"`). When empty, the last path segment of `FileId` (without any query string) is used. |
| **Id** | `string` | No | Generated string | The HTML `id` attribute of the container. If not specified, an ID in the format `attach-{8 hex chars}` is generated. |
| **ActionUrl** | `string` | No | `"/Common/PreviewAttachment"` | Base path for the download and preview URLs. |

## Behavior

- **File type:** The extension of `FileName` (or `FileId`) is mapped to `pdf`, `image`, `word`, `excel`, or `other`. The type is only passed to the preview function; no file-type icon is rendered.
- **Preview:** The preview (eye) button calls the global `openAttachmentFromUrl(fileId, fileName, fileType)`, which builds `{ActionUrl}/{FileId}` and, in order of availability:
  1. calls `showFilePreview(url, fileName, fileType)` (from the `_FilePreview` partial),
  2. calls `window.openPdfViewer(url, fileName)`,
  3. opens the URL in a new tab.

  If `FileId` is empty, it shows a status modal with the message `الملف غير متاح` (file not available).
- **Download:** The download icon is a link to `{ActionUrl}/{FileId}` with the `download` attribute set to the file name. Browsers only honor `download` for same-origin URLs.
- `FileId` is inserted into the URL as-is (not URL-encoded).

## Examples

### Minimal Example
```html
<partial name="UI/_AttachBox" model='new { FileId = "48392", FileName = "Consultation Summary.docx" }' />
```
*Note: `FileName` can be omitted. The display name is then taken from the last path segment of `FileId`, which for a plain ID such as `"48392"` is the ID itself, and no file type can be detected.*

### Full Example with all arguments
```html
<partial name="UI/_AttachBox"
    model='new {
        FileId = "8582",
        FileName = "Consultation Summary.docx",
        Id = "my-custom-attach-box",
        ActionUrl = "/Common/PreviewAttachment"
    }'
/>
```

## Dependencies

- **`UI/_FilePreview` partial** (provides `showFilePreview`) and the **`UI/_StatusModal`** partial (provides `showStatusModal`). Both are rendered by every AttachBox instance, so a page with several AttachBoxes renders them several times. `_FilePreview` is not documented in this repository.
- An endpoint at `{ActionUrl}/{FileId}` that returns the file.
- Bootstrap 5 CSS (`mb-2`, `text-truncate`).

The partial outputs its `<style>` block (`.ab-*` classes) every time it is rendered.

## Known Limitations

- `window.openAttachmentFromUrl` is defined only once per page and uses the `ActionUrl` of the **first** AttachBox rendered. Later instances with a different `ActionUrl` still preview from the first path (their download links are correct). AttachmentCard defines a function with the same name, so on a page with both, whichever component renders first decides the preview path for both.

## Accessibility

- The preview button and download link contain only icons and have only a `title` (`معاينة` / `تحميل`), no `aria-label`.
- The file name is shown with `text-truncate` and its full text in a `title` attribute.

## Security Notes

- `FileId` and `FileName` are placed inside a JavaScript string in the preview button's inline `onclick` attribute. Razor's HTML encoding is decoded by the browser before the script runs, so a value containing `'` breaks the handler, and a crafted value can execute script. Only use trusted, sanitized IDs and file names.
- In the rest of the markup, values use normal Razor encoding.

@using Microsoft.AspNetCore.Routing
@model dynamic
@{
    // ── Parameter extraction ──────────────────────────────────────────────────
    string FileId    = "";
    string FileName   = "";
    string Id         = "";  // optional — auto-generated when empty
    string actionUrl  = "/Common/PreviewAttachment";  // optional — overridable via model

    if (Model != null)
    {
        var props = new RouteValueDictionary(Model);
        if (props.TryGetValue("FileId",     out var fu))  FileId    = fu?.ToString()  ?? "";
        if (props.TryGetValue("FileName",   out var fn))  FileName  = fn?.ToString()  ?? "";
        if (props.TryGetValue("Id",         out var fid)) Id        = fid?.ToString() ?? "";
        if (props.TryGetValue("ActionUrl",  out var au) && !string.IsNullOrWhiteSpace(au?.ToString()))
            actionUrl = au.ToString()!;
    }

    // Display name fallback (used to compute FileName as well)
    if (string.IsNullOrWhiteSpace(FileName))
    {
        FileName = System.IO.Path.GetFileName(FileId ?? "").Split('?')[0];
    }
    var DisplayName = FileName;

    // Auto-generate a unique id when none is provided
    if (string.IsNullOrWhiteSpace(Id))
        Id = "attach-" + Guid.NewGuid().ToString("N").Substring(0, 8);

    // Infer type from file extension when FileType is not supplied
    string GetExtensionType(string name, string url)
    {
        var src = !string.IsNullOrEmpty(name) ? name : url ?? "";
        var ext = System.IO.Path.GetExtension(src).ToLowerInvariant().TrimStart('.');
        return ext switch
        {
            "pdf"                          => "pdf",
            "jpg" or "jpeg" or "png"
                or "gif" or "bmp"
                or "webp" or "svg"         => "image",
            "doc" or "docx"               => "word",
            "xls" or "xlsx" or "csv"      => "excel",
            _                              => "other"
        };
    }

    string FileType = GetExtensionType(FileName, FileId).ToLowerInvariant();

    // Can this type be previewed inline in a browser?
    bool CanPreview = true;
}

                    title="معاينة"

@await Html.PartialAsync("UI/_FilePreview")
@await Html.PartialAsync("UI/_StatusModal")

<script>
    if (typeof window.openAttachmentFromUrl === 'undefined') {
        window.openAttachmentFromUrl = function (id, fileName, fileType) {
            if (!id) {
                 showStatusModal({
                    type: 'info',
                    title: 'الملف غير متاح',
                });
                return;
            }

            let url = `@actionUrl/${ id }`;

            // Use the shared file viewer modal
            if (typeof showFilePreview === 'function') {
                showFilePreview(url, fileName, fileType);
            } else if (window.openPdfViewer) {
                window.openPdfViewer(url, fileName);
            } else {
                // Fallback: open in new tab
                window.open(url, '_blank');
            }
        };
    }
</script>
